# Ganymede 제품 화면 통합 배포

2026-09-24 · `codex/product-redesign-1-3`

## 확정된 범위

사용자가 전달한 저장소·배포 확인에 따라, 이번 제품의 실행 범위는 **USTX 모델 NAV와 구성 공개, 기존 CORE 테스트넷 지분 장부 읽기, 별도 Lab 모의 운용**이다. 실제 입출금·자산 취득·보관·지급·결제 토큰을 새로 만들거나 지정하지 않는다. 실제 투자·회수 구현은 완료한 것으로 표시하지 않는다.

USTX와 GMDCORE는 다른 대상이다. USTX는 지분·결제 계약이 없는 모델 바스켓이다. 배포된 `GanymedeFundShare`는 X Layer Testnet(1952)의 CORE 장부이며, 발행자 mint/burn은 입금·출금 증거가 아니다.

공통 메뉴는 Markets / Portfolio / Activity다. 모바일 하단 메뉴, 키보드 포커스, 메뉴 바깥 클릭·Escape 닫기, 짧은 선택/상태 모션과 움직임 줄이기 CSS를 유지했다. 조회 오류는 0 또는 성공으로 바꾸지 않는다. 계정이 바뀌면 이전 계정 잔액을 보여주지 않는다.

장부 조회는 체인 ID, 배포 주소의 코드, decimals를 확인하고 같은 블록으로 잔액을 읽는다. 최근 2,000블록의 제한된 이력임을 화면에 표시하며 오래된 기록은 탐색기로 연결한다. 공개 RPC의 100블록 제한에 맞춰 최대 3개 동시 요청으로 나누어 읽는다. 계정 연결은 공개 주소 조회 권한 요청뿐이며 인증·서명·송금으로 사용하지 않는다. 공개 주소 편의 저장은 해당 탭의 sessionStorage만 쓴다.
