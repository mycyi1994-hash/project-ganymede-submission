## 확정된 범위

제품의 실행 범위는 **USTX 데모 투자(데모 달러로 매수·환매, 바스켓 들여다보기, 펀드 개요), USTX 모델 NAV와 구성 공개·브라우저 검증, 발행 좌수의 X Layer 기록, 공개 NAV API와 임베드 배지, X Layer 메인넷 xStocks 읽기 전용 평가, 기존 CORE 테스트넷 지분 장부 읽기, 별도 Lab 모의 운용**이다. 실제 입출금·자산 취득·보관·지급·결제 토큰을 새로 만들거나 지정하지 않는다. 데모 주문은 실제 돈이 오가지 않으며, USTX 지분은 데모 장부에만 있고 체인에 발행되지 않는다.

USTX와 GMDCORE는 다른 대상이다. USTX는 지분·결제 계약이 없는 모델 바스켓이며, 투자는 브라우저별 비공개 데모 계정(쿠키, 해시로만 저장)의 데모 달러로만 한다. 배포된 `GanymedeFundShare`는 X Layer Testnet(1952)의 CORE 장부이며, 발행자 mint/burn은 입금·출금 증거가 아니다.

`/activity`의 장부 조회는 체인 ID, 배포 주소의 코드, decimals를 확인하고 같은 블록으로 잔액을 읽는다. 최근 2,000블록의 제한된 이력임을 화면에 표시하며 오래된 기록은 탐색기로 연결한다. 공개 RPC의 100블록 제한에 맞춰 최대 3개 동시 요청으로 나누어 읽는다. 계정 연결은 공개 주소 조회 권한 요청뿐이며 인증·서명·송금으로 사용하지 않는다. 공개 주소 편의 저장은 해당 탭의 sessionStorage만 쓴다.
